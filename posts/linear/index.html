Introduction

Linear Regression is often the first algorithm we encounter in our Machine Learning journey. On a surface level, it’s deceptively simple: it’s just a line passing through some data points. Most people look at the classic slope formula $y = mx + c$ we learn in school

If you peel back the skin, what looks like a simple line is actually the result of solving an optimization problem. Behind this ‘simple’ line lies elegant calculus, linear algebra, and statistics. To truly understand how a machine "learns" this line, we have to look at it through two distinct lenses:

  1. The Closed-Form Solution (OLS): The "one-shot" mathematical approach using the Normal Equation/closed-form derivation from calculus,

  2. The Iterative Optimization (Gradient Descent): The foundation of how almost all modern neural networks actually learn.

So in this blog we will cover what is linear regression and the Closed from solution which is easy to understand

So what is Linear Regression ??

Linear Regression is both a supervised learning algorithm and a statistical technique used to model the relationship between a continuous dependent variable and one or more independent variables by fitting a straight line.

In simple terms, it finds the line that best represents the scattered data points and then uses that line to predict unknown values. But the phrase ‘best represents’ requires a mathematical definition.

But how do we know which line is truly the best for a given dataset?
A machine cannot rely on intuition it needs precise mathematical guidance.

Humans may judge visually, but machines require measurable criteria. A machine cannot rely on intuition; it must rely on mathematics. Therefore, we must convert this intuition into a mathematical objective.

This measurable difference is what we call error. By defining error explicitly, we transform the problem into an optimization task.

This idea leads us to the concept of error and the optimization process that lies at the heart of linear regression.

So now we have a question

How does a machine compute the best possible line in one step?

The answer lies in solving the optimization problem analytically. This is where the closed-form solution emerges. By minimizing the defined loss function, we can directly compute the optimal parameters.

So we will discuss about closed form solution by minimizing loss function

Formulating the Loss Function

Now we move from intuition to mathematics.
Let us assume we are given a dataset consisting of $n$ data points:

$$ (x_1, y_1), (x_2, y_2), \dots, (x_n, y_n) $$

When we fit a linear model to this dataset, we obtain a regression line of the form :

$$ \boxed{\hat{y} = mx_{i}+c} $$

However, this line does not perfectly pass through every data point. The predicted values generally deviate from the actual values. This deviation is what we call the error (or residual), and it plays a crucial role in optimizing the model.

From the visual representation, we can define the error for each data point as:

$$ e_i = y_i - \hat{y}_i $$ where, $y_i - Actual$ $\hat{y}_i - Predicted$

To measure the total error made by the regression line, we square each residual and sum them across all data points. This gives us the error function:

$$ E = \sum_{i=1}^{n} e_{i}^{2} $$

[NOTE] We square the function because to remove the negative values form the error we can't use mod because Mod function is not differentiable

we can call E as error function of given linear regression line

Substituting the definition of $e_{i}$ , we get: $$ E = \sum_{i=1}^{n} (y_i - \hat{y}_i)^{2} $$ we can write rewrite the above error function as function of two variables m and c such as

$$ E(m,c) = \sum_{i=1}^{n} (y_i - m x_{i} - c)^{2} $$ since ${\hat{y} = mx_{i}+c}$

Now the error function is expressed entirely in terms of the parameters mmm and ccc.

Our objective is to find the values of m and c that minimize this function.

Understanding the Error Function Geometrically

Before finding the optimal solution for our model, it is important to understand how the error function behaves with respect to the parameters $m$ and $c$.

In machine learning, the error function plays a central role because it tells us how good or bad our model is for a given set of parameters. Optimization is not magic it is simply the process of adjusting parameters to reduce this error. Therefore, without understanding how the error function behaves, we cannot truly understand how the model reaches its optimal solution.

Recall that our error function is: $$ E(m,c) = \sum_{i=1}^{n} (y_i - m x_{i} - c)^{2} $$ This function does not depend on the data alone it depends on the parameters $m$ and $c$.

Case 1: Error as a Function of One Variable (Fix c)

To simplify understanding, assume for a moment that ccc is fixed.

Then:

$$ E(m) = \sum_{i=1}^{n} (y_i - m x_{i} - c)^{2} $$ Now the error depends only on $m$

Notice that each term in the summation is squared.
If we expand the expression inside the square, it becomes a quadratic function in mmm. Since the sum of quadratic functions is still quadratic, the overall error function is quadratic in mmm.

And what does a quadratic function look like?

A parabola.

When plotted with respect to $m$, the error function forms a U-shaped curve (parabola).

Because the squared term ensures positivity, the parabola opens upward. This means:

  • There exists a single minimum point.

  • There are no multiple local minima.

Therefore, our objective is to find the value of mmm that corresponds to the lowest point of this curve.

For now, we aim to reach this minimum in a single analytical step .To locate this minimum precisely, we turn to calculus.

Case 2: Error as Function of Both m and c

Now lets see how the error function would look like if you consider whole error function

we have: $$ E(m,c) = \sum_{i=1}^{n} (y_i - m x_{i} - c)^{2} $$ This is a Quadratic function in $m$ and $c$

When you plot this in 3D:

  • x-axis → m

  • y-axis → c

  • z-axis → error

You get a convex bowl-shaped surface.

It have only one global minimum and no local minima and also the surface of graph is smooth and differentiable

Since the error surface is convex and smooth, the minimum can be found by identifying the point where the slope becomes zero in all directions. This is precisely what calculus allows us to do.

[NOTE] In this article, we obtain the minimum analytically using the closed-form (OLS) solution. Although we do not explicitly “walk” on this surface, this geometric interpretation becomes especially useful when studying Gradient Descent, where the algorithm iteratively moves toward the minimum along this convex surface.

Minimizing the Loss Using Calculus

To minimize the loss function, we compute the partial derivatives of $E(m,c)$ with respect to $m$ and $c$ and set them equal to zero.

We have: $$ E(m,c) = \sum_{i=1}^{n} (y_i - m x_{i} - c)^{2} $$

Let's differentiate partially by setting up derivatives:

$$ \frac{\partial E}{\partial m} = 0,\frac{\partial E}{\partial c} = 0 $$

Partial derivative with respect to c: $$ \frac{\partial E}{\partial c} = \sum_{i=1}^{n} 2 (y_i - m x_i - c)(-1) $$

$$ \frac{\partial E}{\partial c} = -2 \sum_{i=1}^{n} (y_i - m x_i - c) $$

Set equal to zero:

$$ -2\sum_{i=1}^{n} x_i (y_i - m x_i - c) = 0 $$

Divide by -2:

$$ \sum_{i=1}^{n} x_i (y_i - m x_i - c) = 0 $$

Expand: $$ \sum_{i=1}^{n} y_i- m \sum_{i=1}^{n} x_i-\sum_{i=1}^{n} c = 0 $$

Solve for c: $$ nc = \sum_{i=1}^{n} y_i - m \sum_{i=1}^{n} x_i $$

$$ c = \frac{1}{n}\sum_{i=1}^{n} y_i- m \frac{1}{n}\sum_{i=1}^{n} x_i $$

Recognize the means:

$$ \bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i, \qquad \bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i $$

$$ \boxed{c = \bar{y} - m\bar{x}} $$

Partial derivative with respect to m: $$ \begin{align} \frac{\partial E}{\partial m} &= \sum_{i=1}^{n} 2 (y_i - m x_i - c)(-x_i) \ &= -2 \sum_{i=1}^{n} x_i (y_i - m x_i - c) \end{align} $$ Set equal to zero:

$$ -2\sum_{i=1}^{n} x_i (y_i - m x_i - c) = 0 $$ Divide by -2: $$ \sum_{i=1}^{n} x_i (y_i - m x_i - c) = 0 $$

Expand:

$$ \sum_{i=1}^{n} x_i y_i- m \sum_{i=1}^{n} x_i^2- c \sum_{i=1}^{n} x_i = 0 $$

Substitute:

$$ \boxed{c = \bar{y} - m\bar{x}} $$

$$ \sum_{i=1}^{n} x_i y_i - m \sum_{i=1}^{n} x_i^2 - (\bar{y} - m\bar{x}) \sum_{i=1}^{n} x_i = 0 $$

Expand:

$$ \sum_{i=1}^{n} x_i y_i - m \sum_{i=1}^{n} x_i^2 - \bar{y} \sum_{i=1}^{n} x_i + m\bar{x} \sum_{i=1}^{n} x_i = 0 $$

We have:

$$ \sum_{i=1}^{n} {x}_i = n\bar{x} $$

Therefore: $$ \sum_{i=1}^{n} x_i y_i - m \sum_{i=1}^{n} x_i^2 - n\bar{x}\bar{y} + mn\bar{x}^2 = 0 $$

Rearrange terms involving $m$:

$$ \sum_{i=1}^{n}x_i y_i - n\bar{x}\bar{y}=m\left( x_i^2 - n\bar{x}^2\right) $$

solve for $m$:

$$ m = \frac{\sum x_i y_i - n\bar{x}\bar{y}}{\sum x_i^2 - n\bar{x}^2} $$

$$ \sum (x_i - \bar{x})(y_i - \bar{y})=\sum x_i y_i - n\bar{x}\bar{y} $$

Therefore: $$ \boxed{m =\frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}} $$

Final Closed-Form Solution:

$$ \boxed{m =\frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}} $$

$$ \boxed{c = \bar{y} - m\bar{x}} $$

Below is a minimal implementation of linear regression using the derived closed-form formulas.

class Linearregression:

    def _init_(self):
        self.m = m
        self.b = b

    def fit(self,x_train,y_train):

        num = 0
        den = 0        
        for i in range(x_train.shape[0]):
            
            num = num + ((x_train[i] - x_train.mean())*(y_train[i] - y_train.mean()))
            den = den + ((x_train[i] - x_train.mean())*(x_train[i] - x_train.mean()))
        
        self.m = num/den
        self.b = y_train.mean() - (self.m * x_train.mean())
        print(self.m)
        print(self.b)  

    def predict(self,x_test):
        print(x_test)
        return self.m * x_test + self.b

Conclusion

What began as a simple straight-line equation turned out to be a structured optimization problem. By defining a loss function and minimizing it using calculus, we derived the exact closed-form expressions for the slope and intercept of the regression line.

$$ \boxed{m =\frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}} $$

$$ \boxed{c = \bar{y} - m\bar{x}} $$

This result reveals something deeper: the slope is essentially the ratio of covariance to variance. In other words, linear regression measures how strongly two variables move together relative to how much one of them varies.

However, solving the optimization problem analytically works efficiently only in simpler settings. As the number of features increases, computing a direct closed-form solution becomes computationally expensive.

Instead of solving the problem in one exact step, we can approach the minimum gradually.

In the next article, we will explore Gradient Descent the iterative optimization algorithm that moves step by step along the same convex error surface to reach the minimum.
